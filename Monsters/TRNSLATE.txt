// =====================================================================
// WEAPON RARITY TIERS -- the elite drop's sprite tint.
//
// NAMED FOR RARITY, NOT NUMBERED. The monster entries above are
// rs_<family>_t<NN> because monsters have numeric difficulty tiers;
// weapons have rarity tiers and take their names. Keeping the two
// vocabularies apart is a standing project rule -- do not renumber
// these to match the monster block.
//
// The '%' prefix is a DESATURATED remap: the engine takes the source
// pixel's LUMINANCE and interpolates along the given range
// (palettecontainer.cpp:744). That is what makes this a tint rather
// than a scramble -- a flat "0:255=[a]:[b]" would remap by palette
// INDEX, and Doom's palette is not ordered by brightness, so the
// sprite would come apart. Shape, shading and readability survive;
// only the hue changes. You can still tell a shotgun from a revolver.
//
// Colours are RS_UIStyle's tier ramp. Each goes dark -> full so the
// sprite keeps its own light and shade.
// =====================================================================
// SYNTAX, twice-bitten (both fixed 2026-08-06, neither was cosmetic):
//   1. The '%' goes AFTER the '=', not in front of the range.
//      "0:255=%[...]" -- palettecontainer.cpp:659-671 reads start:end=
//      FIRST and only then looks at the marker, so a leading '%' dies as
//      "Expected integer constant but got '%'".
//   2. The channel values are MULTIPLIERS clamped to 0.0-2.0
//      (palettecontainer.cpp:542-547), NOT palette bytes. Written as
//      0-255 they all clamp to 2.0 and every tier comes out the same
//      blown-out white -- which compiles clean and looks like a bug in
//      something else entirely. Values below are the intended 0-255
//      ramp divided by 255; the original byte value is in the comment.
//   3. THESE WERE A FIFTH LADDER, and it was one rung out. Fixed
//      2026-08-12, when the rarity token drop became the first thing to
//      actually call them.
//
//      RS_TierPalette.zs exists because four separate tier ladders had
//      drifted apart; its header says all four now forward to it. This
//      block was the one nobody found, because nothing called it -- so
//      nothing ever drew the wrong colour and nothing ever complained.
//      It read Common WHITE, Uncommon GREEN, Advanced BLUE, Designer
//      PURPLE, Prototype GOLD: the whole set shifted one rung down the
//      palette's Common GREEN, Uncommon BLUE, Advanced PURPLE, Designer
//      YELLOW, Prototype CYAN.
//
//      Values below are now derived from RS_TierPalette.RGB() and
//      nowhere else. The bright end IS the palette colour over 255; the
//      dark end is that colour at roughly 7%, which keeps the shadows
//      tinted rather than crushing them to black. If the palette moves,
//      MOVE THESE -- a translation cannot ask a ZScript class for a
//      number, so this is the one place the single source of truth has
//      to be copied by hand, and it is the reason it drifted before.
//   4. A WASH IS NOT A FILL. Corrected 2026-08-12 the first time one was
//      seen in play: the shotgun came out a flat neon-green silhouette
//      with no barrel, no stock and no shading.
//
//      The straight palette colour over 255 crushes the off-hue channels
//      -- Common (40,255,60) becomes [0.16,1.00,0.24], so red and blue
//      can never exceed a sixth of full and every pixel of the sprite
//      differs only in how much GREEN it has. Hue arrives, contrast
//      leaves, and the thing stops reading as a weapon.
//
//      So the bright end is lifted off the floor:
//
//          bright = 0.30 + 0.70 * (channel / 255)
//          dark   = 0.03 + 0.10 * (channel / 255)
//
//      The 0.30 pedestal is what keeps the other two channels alive, so
//      highlights stay near-white and the silhouette keeps its detail
//      while the midtones carry the tier. Identifying the WEAPON matters
//      as much as identifying the rarity -- the whole reason the drop
//      wears its own pickup is so you can tell an SMG from an SSG across
//      a room.
