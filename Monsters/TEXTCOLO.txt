// TEXTCOLO -- font colour translations.
// ---------------------------------------------------------------------
// RSScore_* are the arcade score readout's palette. They are gradients,
// not flat colours: a dark low end and a bright high end, which is what
// keeps the bonus stack readable over a bright floor.
//
// This lump exists because the stock console colours are NOT these
// colours. An earlier pass mapped the four flavours onto the nearest
// CR_* constants -- CR_BRICK / CR_GREEN / CR_ORANGE / CR_WHITE. Three
// were merely in the right hue family; the fourth was simply wrong, and
// the base line rendered white when it is meant to be gold. Do not
// "simplify" these back to CR_ names.
//
// Flavour meanings, matching RS_ScoreDefs.RS_SF_*:
//   Base        the kill itself
//   Efficiency  Spree, Untouchable, Infighter
//   Style       Switcharoo, Scrapping, Telefragged, Curveball, Darwin, Air
//   Daring      Redline, Swan Song, Point-Blank, Brawler, Giant Slayer
// =====================================================================
