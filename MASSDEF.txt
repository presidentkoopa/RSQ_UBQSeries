// ============================================================================
// RSQ_DistanceGrab -- WHAT DOOM'S OWN THINGS WEIGH, in kilograms.
//
// The desktop RS_WorldHands table, carried across unchanged so the two
// families agree about every object, plus the one line below it that the pull
// needs and the hand never did. Same lump name and format on purpose: it is a
// shared format, every MASSDEF in the load order is read, and a later line for
// the same class wins -- so a weapons pack can correct any number here by
// shipping its own.
//
// In the pull a weight becomes a SHARE of the pull's strength, k/(k+kg) with
// k = rsqdg_pull_kg (10 by default): a clip arrives at full speed, the barrel
// at about a third of it, a Cacodemon corpse at a slow drag. See mass.zs.
// ============================================================================

//   mass "<class>" <kg> [drag <n>] [flutter] [impact explode]
//
// All three are read. `drag` (per unit/tic, Vel /= 1 + drag x speed) and `flutter` (a
// sideways wobble while it falls) act on anything that has left a hand, as in the
// desktop RS_Flight (throw.zs, the air); `impact explode`: a thrown one that lands
// hard goes off (throw.zs).

// ---- props ----------------------------------------------------------------
// THE BARREL IS THE SHOWPIECE. 60 kg keeps a third of the arm's speed one
// handed and a half with two, which is the difference between a shove and a
// heave -- and it is the object most likely to be picked up and thrown at
// something. `impact explode` lets a hard landing set it off.
mass "ExplosiveBarrel"  60.0   drag 0.001   impact explode

// ---- the pull adds ----------------------------------------------------------

// volume guess turns into 300 kg and clamps to the 200 kg ceiling -- heavier
// than its explosive cousin by more than three times. It is the same drum.
