## F1: A level earned by a gun that is not in your inventory stops the game
- Kind: possible bug
- Where: WeaponInfo.zsc:234-251 (Fanfare), :270 (StartLevelUp); reached from PerPlayerStats.zsc:1392 (XP paid to every record in the credit list) through :1326 and WeaponInfo.zsc:229
- What the code does: when a hit takes a record's XP across its level cost, Fanfare runs `wpn.owner.A_SetBlend`, `wpn.owner.A_StartSound`, then `wpn.owner.A_Log` or `wpn.owner.GiveInventoryType`. Every branch uses `wpn.owner`. This mod pays XP to records whose gun is not owned: a gun thrown with RSQ Tactical Rig pays its own record (PerPlayerStats.zsc:1133-1139; the Rig's thrown gun has no owner, TacticalRig/zscript/rsqtr/rig.zs:1672 and :1703); a dropped gun's rocket still in flight and a dropped gun's burn still ticking pay the dropped gun (the record is kept alive for exactly that, PerPlayerStats.zsc:652-661, :669-682). For those `wpn.owner` is null, or `wpn` itself is null when the gun was destroyed.
- Why it looks wrong: the hit that fills the bar is a call on nothing: the script aborts and the game drops to the console. It needs the level to be crossed by that very hit, so it is rare, but a thrown gun's hit is up to 60 damage and any gun you have held has a record.
- Sure?: likely. Certain about the code path. A rig test settles it: give a gun XP to just under its level cost, throw it at a monster with the Rig.
- Fix A: in Fanfare and StartLevelUp use the player the stats belong to (`stats.owner`) in place of `wpn.owner`, and the record's class name when `wpn` is null (about 8 lines, 1 file).
- Fix B: when the record's gun is not owned, add the XP and skip Fanfare; the level waits and shows the next time the gun is held and the info key is pressed (about 4 lines, 1 file).
- Or intended: no README line; this cannot be meant.
