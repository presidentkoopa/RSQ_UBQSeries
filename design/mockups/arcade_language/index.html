Doom Arcade VR: the world talks back

Eight mockups, one per pattern. Each is a real rig frame (QuestZDoom 17.3, left eye, Brutal Doom 22 monsters, Doom II maps) with the overlay drawn where it would sit in the world. Only the series' own fonts and Doom palette colours; glows and outlines, no boxes. Each panel says its font, colours and size in metres. Mockups only: no mod code was changed. Click a panel for full size.

All eight are design mockups: nothing here is built, nothing is rig- or headset-tested as a feature. The backgrounds are frames from the test rig (doom2 → brutal22test6 → BD_VoxelPack → BD22 VR, plus RSQ VisualRewards for the bits in panel 8), frozen with the freeze cheat. Sizes in metres assume 32 map units per metre. Contact sheet: contact_sheet.png. Rebuild: python3 -I src/panels.py p1 p2 p3 p4 p5 p6 p7 p8.
