### Independent review, and what it changed

A separate reviewer read the diff cold. Fixed from it, each re-verified in the rig:

- **Catch flash never drew** — stamped `maptime + 1`, so age was -1 on the catch
  tic. Now stamped this tic with a separate on-flag; traced drawing ages 0–8.
- **Item taken mid-air kept the borrowed flags** — `BecomeItem` does not restore
  NOGRAVITY/THRUACTORS/size; a later drop would float. Restored there now.
- **"Body frame" was the head frame** — on QZD `pmo.Angle` follows the headset.
  Now un-rotated by an inferred TRACKING yaw (turns only when both hands follow),
  and a head turn blanks the throw sampler for two tics — the engine reports the
  hands rotated the wrong way for one tic on every head turn (measured). Rig:
  head glance / smooth head turn / snap turn → 0.0 m/s drop; jerk → 10.5 m/s throw.
- Services cached (were looked up per candidate per tic); an exact MASSDEF row
  beats a measured gun, but a measured gun beats an INHERITED row; a corpse
  raised mid-pull ends the pull and keeps its living size; a dying barrel is not
  pullable; mod-registered guns/barrels obey the menu switches; `pull.refused`
  said once per flight; arrival uses the same room distance as the catch; haptic
  busy window is wall-clock (MSTime) so a two-tic frame cannot swallow a tick;
  `Hold.Drop` tells `hold.drop`; debug/trace fallbacks now match CVARINFO (false).

Not changed: lock-clearing on level change sends no `pull.unlock` (nothing is
listening across a map change); consoleplayer-driven playsim spawns would desync
netplay, like the rest of the package (owner: netplay is not a concern on Quest).

`build.ps1` → VERIFIED OK. Rig: compiles, reaches MAP01, zero script errors and
