## F1: With RSQ Score loaded, a common monster drops a quarter fewer bits (Gold Bits Off or Gold From: Every Kill already avoid it)
- Kind: possible bug
- Where: zscript/rsqvr/killrewards.zs:497-500 (Burst), :541 (BurstCapped), :996-1000 (Share: 25 whenever Score's bank is there), :303 (goldOK false for any kill that is not a Big Boss, a Boss or a legendary champion); CVARINFO.txt:100-101
- What the code does: each roll that drops first rolls the Gold Share (25%). If this death may not drop gold, a roll that comes up gold drops nothing (`++lastGoldOff; continue`). Without Score, Share() is 0 and that roll never happens.
- Why it looks wrong: loading Score (with the defaults Gold Bits On and Gold From: Special Kills Only) takes about 25% of every common kill's health, armour and ammo bits away. Steel bits drop by a quarter too, because they roll only on what is not a gold roll. The comment at :461-462 says the other bits are "exactly what they were", but that is only true compared with gold on every kill, not compared with no Score.
- Sure?: certain about the code. Whether it was meant is an owner answer.
- Fix A: when goldOK is false, skip the gold roll entirely, so the roll goes on to steel and the mix (2 lines, killrewards.zs :497 and :541).
- Fix B: leave it; the README says so (the new README's Limits already does).
- Or intended: README: "With RSQ Score loaded, a quarter of a common monster's drop rolls are gold rolls that drop nothing."

## Built 2026-11-27

  the normal mix and loading RSQ Score costs a common kill no bits. The counter for gold rolls that dropped nothing
  (lastGoldOff) is gone; the Gold Log now says "may not drop gold (...): no gold roll" for such a kill.

  FightBurst, Arrive and the three bits' TryPickup; the Lucky Kill queue, its burst in WorldTick and LuckyWhy ("kr.lucky",
  "kr.luckyfx"); the Scavenger 3 block in the ammo bit. MagnetM returns the Bits Fly to Me row. RSQVR_Service no longer
  answers "kr.perk" or "kr.magnet" (service.zs; its GetDouble override went with "kr.magnet"). Bits are always 25 health,
  10 armour, 5 rounds (times the bits one stands for over the cap). CVARINFO's Bits Fly to Me comment no longer describes
  the Magnet node. No setting was retired (none belonged only to these nodes).
- F8, owner: "Keep it as the code has it". Built. The dead kind-3 (map boss) branches are deleted (goldShareOff, the Gold
  Log's map-boss text, FountainCount's kind 3) and the comments now name the three sources only: a Big Boss, a Boss, a
  legendary champion; a map boss, a plain Champion and a plain legendary drop none.
- F10: built as toasts (owner 2026-11-27: "i want them in world but i want them at the bottom of the hud as well ... like
  the other hud messages we get"). Reward Words keeps its default World and there is no settings move; the world signs are
  as they were. With a player's Reward Words on World, every LEVEL UP!, REVIVE!, REVENGE! or 1UP sign put up for him
  (worldwords.zs WorldWord, never for a label) also queues one toast through the mod's own toast path (banners.zs
