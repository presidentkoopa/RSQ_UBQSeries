// THE OPTIONS, AND EVERY PAGE MUST BE REACHABLE.
//
// An orphaned OptionMenu compiles clean, loads clean and says nothing. In a
// headset it reads as the feature having been removed -- which is exactly what
// happened to ten pages of the desktop package when it was split out, because
// they hung off a parent menu that did not come across. So: this file has one
// root, it is added to the engine's own Options menu, and every page below is
// linked from it. build.ps1 checks that nothing is orphaned.

AddOptionMenu "OptionsMenu"
{
	StaticText ""
	Submenu "Distance Grab", "RSQDG_Options"
}
