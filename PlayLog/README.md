# RSQ PlayLog

Writes down how you actually play, so the series can be tuned from real play instead of guesses. It changes nothing in the game and loads alone.

**To record:** Options → RSQ Play Log → turn **Record Play Log** on → **Start Log File**. Play. Then **Stop Log File**. The file is `rsqplay.txt` in the game's own folder. Starting the file again starts it over, so copy it out first.

What it writes (lines starting `RSQLOG`): every swing of each hand (peak speed, direction, what the hand held), kills (what, with what, how far), damage taken, deaths, map start and end with times, and each second the draws and the longest wait between two (hitches of 50 ms or more are called out).

Code only, not run in the headset.
