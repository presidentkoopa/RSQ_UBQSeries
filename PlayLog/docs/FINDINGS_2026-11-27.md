Read at commit a283738bb. Read whole: zscript.txt, zscript/rsqpl/handsync.zs, zscript/rsqpl/log.zs, CVARINFO.txt,

**The keys plan:** PlayLog is not in design/KEYBINDS_PLAN.md, and it has no KEYCONF. They agree.

**RSQ Accessibility (being removed): every place this mod reads it.** log.zs:113-123 only. It looks for RSQG_Service
(:113) and keeps only that exact class name (:117). It asks "inspect" and "pulse" (:118) and "pose.why" for "pulse" and
"watch" (:123), always for hand 1 (the off hand), with the console player's pawn. Without Accessibility the loop finds
nothing and no WRIST line is written, with no message. Text only: log.zs:14-16 (the header). The mod answers no service
of its own. See F1.

**What it writes:** RSQLOG lines to the console only (MAP, END, SWING, WRIST, KILL, HURT, DIED, FPS, HITCH). A file
only through the menu's Start Log File, which runs the engine's `logfile rsqplay.txt` (MENUDEF.txt:12). That file holds
the whole console. From FPS alone it grows about 50 bytes a second (one line of about 48 characters a second,
log.zs:170), about 180 KB an hour, plus up to 5 WRIST lines a second while the off hand is at the face. Nothing caps it.

Ordered by what a player would meet first. Wording and comment mismatches are at the end.

## F1: The WRIST lines ask RSQ Accessibility, which is going; RSQ Gun Cards now answers the same three requests
- Kind: other
- Where: log.zs:113 and :117 (RSQG_Service, by exact class name); Accessibility/zscript/rsqg/gestures.zs:965; GunCards/zscript/rsqgc/gestcopy.zs:408-432 (RSQGC_GCopyService answers "inspect" at :418, "pulse" at :419 and "pose.why" at :427-431, with the same arguments: intArg the hand, objectArg the pawn; "pose.why" only for the console player's pawn, which is what log.zs passes)
- What the code does: once RSQG_Service is gone, no WRIST line is ever written.
- Why it looks wrong: when Accessibility is removed, WRIST disappears from the log without a word, though Gun Cards could answer it.
- Sure?: certain.
- Fix A: the repoint. Change "RSQG_Service" to "RSQGC_GCopyService" in log.zs:113 and :117 (one name, 2 lines, 1 file). Gun Cards answers 0 or 2, never 1 ("entering"), and "pulse" answers -1 with Wrist Turn on Either Way (gestcopy.zs:391-395). So the header's "0 not, 1 entering, 2 held" (log.zs:15) should read "0 not, 2 checked" (1 comment line).
- Fix B: ask RSQGC_GCopyService first and RSQG_Service only if it is absent, while both exist (about 6 lines).
- Or intended: WRIST goes with Accessibility; delete Wrist() and its call (about 22 lines).

## F3: After loading a saved game, END counts the seconds and deaths from the load, not from the map's start
