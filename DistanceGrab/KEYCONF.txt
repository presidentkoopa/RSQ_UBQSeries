// THE INPUT, AND IT IS NOT A BUTTON BIT.
//
// Every usercmd bit is contested by mods we cannot see or modify. The lesson
// was learned twice here: BT_USE turned out to be read by our own shield, and
// BT_USER1..4 are used by a bullet-time mod, a grappling-hook mod and Brutal
// Doom. A census only ever sees your own packages.
//
// A KEYCONF action consumes NO usercmd bit, so contention is structurally
// impossible however many mods are loaded. (RSQ_Saber used it for its non-trigger
// inputs, the shipping precedent on this engine, until its keys went 11-10; its
// training remote's Command row still runs a KEYCONF alias.)
//
// HOW THE PRESS AND THE RELEASE BOTH ARRIVE. `+name` is not a buttonMap action,
// so it falls through to alias lookup; and key-up rewrites the leading `+` to a
// `-`, so binding a key to `+rsqdg_main` gives `-rsqdg_main` when it is let go.
// Two aliases, two netevents, a real press/release pair -- which is what makes a
// hold gesture possible on a channel that only reports edges.
//
// A netevent reaches NetworkProcess at the TOP of the tic, before
// P_PlayerThink -- earlier than WorldTick, so better timing than reading a bit.
// It is replicated and it names the player who pressed it.

// (no default binds since 11-10: G is Brutal Doom's Toss Grenade, which RSQ Grenade's quick throw reads; owner: keys
// are precious in VR)
addkeysection "RSQ Distance Grab" RSQDG
addmenukey "Grab / pull (main hand)" "+rsqdg_main"
addmenukey "Grab / pull (off hand)"  "+rsqdg_off"

// ONE ACTION PER HAND, rather than one action and a guess.
//
// A shared input would have to pick the hand geometrically -- "whichever hand
// has a cone target, main breaks the tie" -- which is what a single BT_USE bit
// would have forced on us, since there is no BT_OFFHANDUSE. Having our own
// channel means we simply bind each hand separately and never guess.
alias "+rsqdg_main" "netevent rsqdg_press 0"
alias "-rsqdg_main" "netevent rsqdg_release 0"
alias "+rsqdg_off"  "netevent rsqdg_press 1"
alias "-rsqdg_off"  "netevent rsqdg_release 1"

// NO DEFAULT BINDS (11-10, above): these are the Grab Keys, read only with Grab Keys on. Bind them in Customize
// Controls ("RSQ Distance Grab") or on its page (Controls). The grip grabs without them (its key codes are read
// directly, as RSQ Grapple's and RSQ Whip's ropes do).
