// RSQ Distance Grab options, modelled on Brutal Doom Quest 2.0's options page (the owner, 10-28):
// ONE front page of real choices (short Title Case rows, groups split by blank lines, choices
// named), sub-pages only for lists of switches, ONE Tuning and Debug page at the end that holds
// every number. No help text; what each setting does is in CVARINFO's comments and the docs. Every
// cvar keeps its row. Preset choices: tools/rsmenu/presets.py (Standard = today's defaults).
//
// EVERY PAGE MUST BE REACHABLE: an orphaned OptionMenu compiles and loads clean and reads in a
// headset as the feature removed. One root, added to Radiant Silvergun Options, every page linked
// from it (tools/rsmenu/menutool.py check finds orphans).

// ---- Radiant Silvergun Options (tools/rsmenu) ----------------------------------------------------
// The series' one Options entry. Every series pk3 carries this same block with its own prefix: the
// parent is PROTECTED, so the first definition stays and later ones add nothing (QZD 17.3 merges a
// protected option menu instead of replacing it); the link row removes any earlier copy of itself,
// so Options shows one row however many series pk3s load. Each mod then adds its own row only.

{
	Class "RSQDG_RSMenu"
	Title "RADIANT SILVERGUN OPTIONS"
}

	RSQDGRSLink "Radiant Silvergun Options", "RSQ_RSOptions"
}
