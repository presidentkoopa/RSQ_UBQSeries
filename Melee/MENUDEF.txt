// RSQ Melee -- MENUDEF. The series' menu (MENU_PASS_BRIEF.md, owner 11-04): ONE page with every option under short
// headers, On/Off first; ONE sub menu, "Test and Debug", with the punch, shove and Headlock numbers, the grip keys and the
// debug log. No help text. Guard, Wall Splat, Ground Pound, Clear Out and Human Shield are RSQMLGbOption rows: with RSQ
// Gun Bonsai VR loaded each greys while its upgrade is not learned (RSQML_Service "menu.locked", service.zs). Hadouken and
// Heavy Hands are plain rows: under Gun Bonsai VR the gloves learn them, but any other fist still plays the row
// (core.zs FistLevel, owner 11-04 "Punch with any fist"), so the row always acts.
// Reset All (RSQMLResetAll) resets every row on both pages.
// ---- Radiant Silvergun Options (tools/rsmenu) ----------------------------------------------------
// The series' one Options entry. Every series pk3 carries this same block with its own prefix: the
// parent is PROTECTED, so the first definition stays and later ones add nothing (QZD 17.3 merges a
// protected option menu instead of replacing it); the link row removes any earlier copy of itself,
// so Options shows one row however many series pk3s load. Each mod then adds its own row only.
