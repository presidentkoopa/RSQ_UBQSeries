Capcom VS SNK 2: Millionare Fight 2001 - Hit Sparks
Ripped and converted by Phantom.of.the.Server


NOTES:
- The images included are already in PCX format

- All the PCX in each folder share the same palette

- Converted from high to low resolution, to be compatible with Mugen's HitDef spark parameters

- The ammount of normal, special and super hit/slash spark animations can be doubled if you
rotate them in the AIR file

- The slash sparks are missing many of their variations, but, since including them all in a char
is an unnecessary burden to the SFF file in my opinion, the 8 variations you can do with these
should be enough

- Axis is constant for the normal attack sparks, but for specials and supers they shake a bit
due to CvS2's environment shake on those attacks. Simply put, you can use the same axis for
each group of normal sparks, but you'll have a bit more trouble aligning the others
