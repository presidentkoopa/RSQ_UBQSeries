# RSQ Melee: findings from reading the code (2026-11-27)

Read at commit 50f608e63. Every ZScript file Melee includes was read whole (zscript.txt and the 18 files under
`zscript/rsqml/`), with KEYCONF, CVARINFO, MENUDEF, MAPINFO, LANGUAGE, MODELDEF and SNDINFO. Nothing was run: no rig, no
headset. Each finding is a question for the owner. Nothing was changed.

Paths are inside `Melee/`. `gloves.zs`, `core.zs`, `shove.zs`, `club.zs`, `headlock.zs`, `guard.zs`, `twohand.zs`,
`slappers.zs`, `sparks.zs`, `a11y.zs` and `service.zs` are in `zscript/rsqml/`. "Old README" is `Melee/README.md` as
committed at 50f608e63 (`git show 50f608e63:Melee/README.md`).

Ordered by what a player would meet first. Wording and comment mismatches are at the end.

**The keys plan (design/KEYBINDS_PLAN.md:6) against the code:** the plan says Melee has no keys, and KEYCONF.txt holds
comments only. The off grip is read by raw key code (headlock.zs:82-92, `rsqml_keys_off`, "443 436"). No engine bind is
matched by its text anywhere in Melee. The only buttons read are a hand's fire (gloves.zs:280) and fire or alt fire
(gloves.zs:1353). Use, jump, crouch and the sticks are not read.

**What the code does not have at all:** a backhand, a kick, and a shove with an empty or open hand. The punch reader has
three kinds (gloves.zs:226: jab, hook, uppercut), an open palm returns before any punch (gloves.zs:551-559), and the
shove needs a gun in the main hand (shove.zs:223). The new README says so under Limits. If any was meant to exist, say so.
