# RSQ Miniboss: findings from reading the code (2026-11-27)

Read at commit a283738bb. Every ZScript file of the series' own (zscript.txt and every file under `zscript/rsqmb/`,
`bk/` included) was read whole, with KEYCONF, CVARINFO (both), MENUDEF (both), MAPINFO, DECORATE, SNDINFO (both),
