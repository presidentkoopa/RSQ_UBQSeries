## F1: With the default ring, the Open Wheel key alone cannot take a gun that shares a slot
- **OWNER 2026-11-27: INTENDED. "why would anyone select a weapon by pressing 'open wheel'?" A gun is chosen with primary fire. No code change.**
- Kind: possible bug
- Where: zscript.zs:1086 (release on a slot card), zscript.zs:1054-1060 (next press), zscript.zs:1077 (its release); KEYCONF:24-25 says "hold it, point either hand at a card, let go to take it"
- What the code does: Ring Layout is Always Group by default. Letting go on an "N WEAPONS" card opens the slot and leaves the ring up. The next press of the key, while a slot is open, goes back to the slots and marks the press as "did not open the ring", so its release picks nothing. A gun inside a slot is taken only by a trigger, Use with the hand in the card, a pull, off hand alt fire, or by keeping the key held while the stick push or a trigger opens the slot.
- Why it looks wrong: "one key: hold, point, release" does not reach most guns on a full loadout by pointing alone. The player lets go on a slot, points at the gun, presses the key again to take it, and is thrown back to the slots.
- Sure?: certain about the code path. Whether it is wanted is the owner's call.
- Fix A: in pressWheel, when a slot is open and a gun card is lit, take that card instead of going back; go back only when BACK or nothing is lit (about 4 lines, 1 file).
- Fix B: when a slot is open, let a press start a new hold (so hold, point, release works inside the slot) and keep the short tap as "back" (about 8 lines, 1 file).
- Or intended: the README keeps its row: letting go on a slot card opens the slot, and a gun in it is taken with a trigger.
